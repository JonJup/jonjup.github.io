MIDFIRE — Licensing and Attribution

Overview

MIDFIRE is a compilation of datasets from multiple sources, each governed by its own license or terms of use. The compilation as a whole is published under CC BY-NC-SA 4.0, but downstream users must additionally comply with the original terms of each constituent dataset as listed below.

Where the original license of a constituent dataset is more restrictive than CC BY-NC-SA 4.0, the original terms take precedence for that component. All datasets were modified during harmonization and do not represent the original state of the data as provided by the source.

Some components have more lenient licenses than the complete MIDFIRE dataset. The non-commercial clause is only valid when including data from the following providers:

  • Bundesministerium für Land- und Forstwirtschaft, Klima- und Umweltschutz, Regionen und Wasserwirtschaft (Austria)
  • Landesbetrieb für Hochwasserschutz und Wasserwirtschaft Sachsen-Anhalt (LHW) (Germany)
  • Biodiversity Monitoring, Switzerland
CC BY-SA 2.0 FR incompatibility: The French data component (Office français de la biodiversité) is licensed under CC BY-SA 2.0 FR, which is incompatible with CC BY-NC-SA 4.0. This component retains its original license within the compilation. Downstream users of the French component may use it commercially but must share derivatives under the same or a compatible ShareAlike license. See Note 6 for details.

Spanish public sector data sources (CHD, CHE, MITECO) operate under the national PSI reuse framework (Ley 37/2007, as amended). Under this framework, reuse — including modification and commercial use — is permitted by default, subject to: source attribution, non-misrepresentation, no implied endorsement, and preservation of update date metadata where available. See datos.gob.es for the overarching framework.

Note 2 — Constituent dataset terms: Where original terms are more restrictive than CC BY-NC-SA 4.0 (e.g., the LHW Sachsen-Anhalt Nutzungsbestimmungen or the BDM Datennutzungsvertrag), users must comply with the original terms for the respective data component. The CC BY-NC-SA 4.0 license does not override or replace these terms.

Note 3 — Data modification notice: As part of the harmonization process, all constituent datasets were modified (taxonomic standardization, format unification, spatial harmonization). They do not represent the original state of the data. See the Methods section of the accompanying publication for details.

Note 4 — No sublicensing guarantee: Some data providers did not grant sublicensing rights. Users intending to redistribute individual components should consult the original terms linked above.

Note 5 — Attribution: When using MIDFIRE, please cite both the compilation and the relevant original data sources as listed in the main publication.

Note 6 — CC BY-SA 2.0 FR incompatibility (French data): The French data component (Office français de la biodiversité, via Naïades) is licensed under CC BY-SA 2.0 FR. This license is incompatible with the compilation's CC BY-NC-SA 4.0 license because the Non-Commercial restriction is more restrictive than the original ShareAlike terms, which permit commercial use. The French component therefore retains its original CC BY-SA 2.0 FR license within the compilation. Downstream users of the French data component may use it commercially, but must distribute any derivatives under CC BY-SA 2.0 FR or a compatible license. Users of the full MIDFIRE compilation (including non-French components) remain bound by CC BY-NC-SA 4.0 for all other components.

Note 7 — Spanish public sector data sources: CHD, CHE, and MITECO operate under Spain's national PSI reuse framework (Ley 37/2007, as amended by Ley 18/2015; RD 1495/2011; Ley 27/2006). Under this framework, reuse — including modification and commercial use — is permitted by default, subject to: source attribution, non-misrepresentation, no implied endorsement, and preservation of update date metadata where available. See datos.gob.es for the overarching framework. Data were modified during harmonization.
