PULSE Interactive Tool

Type Coherence Prediction

An interactive application for predicting how well a proposed river typology will perform — before you invest the effort of building one. Powered by Quantile Random Forest models trained on thousands of simulated typology scenarios across European freshwater systems.

Launch the app
Opens in a new tab · Hosted on CSC Rahti

What does it do?

The app takes a set of typology characteristics — number of types, spatial extent, environmental distinctiveness, taxonomic resolution, and more — and returns a predicted evaluation score with uncertainty bounds. This lets you explore how design decisions affect typology quality before committing to a full analysis.

Under the hood, the predictions come from Quantile Random Forest models fitted as part of the PULSE project. These models were trained on a large simulation study that systematically varied typology parameters and evaluated the resulting classifications against multiple coherence metrics.

Supported taxonomic groups

🌿 Diatoms 🐟 Fishes 🦗 Macroinvertebrates 🌱 Macrophytes

Features

📊

Quantile predictions

Get not just a point estimate but the full range of plausible outcomes — 10th, 50th, 90th percentiles and more.

🔧

Flexible inputs

Toggle which parameters you want to specify. Unknown values are imputed from training data medians.

📋

Batch mode

Upload a CSV with multiple scenarios and get predictions for all of them at once. Download results for further analysis.

🎯

Multiple metrics

Evaluate typologies against different coherence criteria — fuzzy divergence, Mantel correlation, silhouette width, and more.

How to use

Select a taxonomic group — choose which organism group your typology targets.
Choose an evaluation metric — pick the coherence criterion you want to predict.
Set your parameters — enter the characteristics of your planned typology: number of types, spatial extent, variable selection, etc.
Generate prediction — the model returns quantile-based predictions showing the expected metric value and its uncertainty range.

Context

This tool is part of the PULSE (Pan-European Freshwater Ecotypologies) project, a DFG-funded research initiative at the University of Helsinki. PULSE develops data-driven approaches to freshwater typology construction and evaluation, with direct relevance to the EU Water Framework Directive.

The underlying models were fitted on a simulation framework that generated typologies across a wide parameter space — varying the number of types, geographic coverage, environmental variable selection, taxonomic resolution, and community composition. Each simulated typology was evaluated against multiple biological coherence metrics, creating the training data for the QRF models.

How to cite

If you use this tool in your work, please cite the PULSE project. A manuscript describing the full methodology is currently in preparation.
